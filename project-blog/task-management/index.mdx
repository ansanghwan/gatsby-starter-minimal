- ### 🗓️ 프로젝트 기간

  2026.08.25 ~ 2026.10.23

- ### 📌 프로젝트 개요
  - Codeit 프론트엔드 단기 심화 과정에서 진행한 **4인 팀 할 일 관리 웹 서비스 구축 프로젝트**입니다.
  - **공통 UI·반응형 레이아웃 구현과 대시보드 API 데이터 연동**을 담당했습니다.

- ### 🛠 주요 담당 업무
  - **CSS 공통 환경, Font·Color Token, 공통 Layout 및 반응형 GNB 구성**
  - **공통 Button 컴포넌트와 주요 페이지 반응형 UI 구현**
  - **TypeScript 기반 API 타입·요청 함수 작성 및 TanStack Query 데이터 연동**

- ### 💡 주요 개발 경험

  #### 1. React 환경에서의 공통 UI 구현
  - 기존 UI 실무 경험을 바탕으로 공통 Layout과 반응형 UI를 구현하고, 팀원들이 동일한 UI 구조에서 기능을 개발할 수 있도록 기반을 마련했습니다.

  #### 2. API 데이터 연동
  - **API 명세 확인 → TypeScript 타입 정의 → API 요청 → TanStack Query 서버 상태 관리 → UI 렌더링** 흐름을 적용해 대시보드 데이터를 연동했습니다.
  - 최근 할 일, 전체 진행률, 목표별 할 일 데이터를 조회하고, 담당 화면에서 Loading / Error / Empty 상태에 따른 UI를 구현했습니다.

  #### 3. 컴포넌트 재사용 및 협업
  - 팀원이 구현한 `TodoItem` 컴포넌트를 대시보드에 재사용하며, UI뿐 아니라 상태와 동작을 포함한 컴포넌트의 재사용 범위를 경험했습니다.
